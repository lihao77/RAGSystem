# 错误模型

全局错误处理在 `backend-ts/src/app.ts`：`HttpError` 保留状态码，Fastify/Zod 校验错误返回 400，非法媒体类型返回 415，未分类异常返回 500。

| 状态码 | 含义 |
|---|---|
| 400 | 请求体、查询或 schema 无效 |
| 401 | 身份、JWT、Widget credential 无效 |
| 403 | 角色或权限不足 |
| 404 | 资源不存在或不属于当前租户 |
| 409 | 状态冲突 |
| 413 | 上传超过限制 |
| 415 | 内容类型不支持 |
| 503 | 可选能力未启用，例如 Widget |
| 500 | 未分类服务错误 |
